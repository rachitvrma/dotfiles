* Noctalia Set Up
I use the =noctalia/wallhaven= plugin, which also takes =api_key= TOML value. To enable it, create a =wallhaven_api_key.toml= file in =$XDG_CONFIG_HOME/noctalia= and pass it using the =[include]= option.

#+begin_src toml

  # ~/.config/noctalia.toml

  [include]
  files = [ "wallhaven_api_key.toml" ]

#+end_src

Inside =~/.config/noctalia/wallhaven_api_key.toml=:

#+begin_src toml

  # ~/.config/wallhaven_api_key.toml
  [plugin_settings."noctalia/wallhaven"]
  api_key = "<api_key>"

#+end_src
