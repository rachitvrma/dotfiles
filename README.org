* Introduction

#+begin_quote
Looks matter. It is a good thing to have utility with a good rice.
#+end_quote

A single-host NixOS configuration, wired together with [[https://flake.parts][flake-parts]] instead of one monolithic =flake.nix=. Every file under [[./modules][modules/]] is a flake-parts module that auto-imports itself via =lib.fileset= --- see [[./flake.nix][flake.nix]] --- so adding a new module is just adding a new =.nix= file, no import list to maintain. Files starting with =_= are skipped by the auto-import (host-local plain NixOS modules). Details in [[./docs/architecture.org][docs/architecture.org]].

* Quick start

#+begin_src sh

  cd ~/etc/nixos
  tack update    # inputs are pinned in .tack/pins.toml, there is no flake.lock
  nos            # alias for: nh os switch   (or: just switch)

#+end_src

The repo is expected to live at =~/etc/nixos=.
