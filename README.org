** Introduction
:PROPERTIES:
:CUSTOM_ID: introduction
:END:

#+begin_note
Looks matter. It is a good thing to have utility with a good rice.
#+end_note

A single-host NixOS + home-manager configuration, wired together with\\
[[https://flake.parts][flake-parts]] instead of one monolithic
=flake.nix=.\\
Every file under [[./modules][=modules/=]] auto-imports itself via\\
=lib.fileset= --- see [[./flake.nix][=flake.nix=]] --- so adding a new
module is\\
just adding a new =.nix= file, no import list to maintain.

| Util                     | Program used                                                             |
|--------------------------+--------------------------------------------------------------------------|
| Shell                    | Zsh                                                                      |
| Desktop Environment      | GNOME                                                                    |
| Editor                   | Emacs (primary) --- Neovim config kept around for in-case scenarios only |
| Terminal                 | Kitty                                                                    |
| Audio                    | PipeWire                                                                 |
| System Monitor           | GNOME System Monitor (Bottom/htop kept installed, purely aesthetic now)  |
| Mail                     | (see [[./modules/accounts][=accounts=]])                                 |
| Chat                     | Vesktop (Discord) · Emacs ERC (IRC) · Emacs ement.el (Matrix)            |
| File Manager             | Emacs Dired                                                              |
| RSS Reader               | Newsticker (Emacs) · Miniflux (self-hosted WebUI)                        |
| Theme                    | Stylix --- Gruvbox Material Dark Hard                                    |
| Browser                  | Firefox (hardened) · w3m                                                 |
| Secrets                  | agenix · pass / GPG                                                      |
| Local AI                 | OpenCode + Ollama                                                        |
| Agenda / Task Maintainer | Emacs + org-mode                                                         |

** Repository layout
:PROPERTIES:
:CUSTOM_ID: repository-layout
:END:
#+begin_example
.
├── flake.nix / flake.lock      # flake-parts entrypoint; auto-imports modules/
├── modules/
│   ├── *.nix                   # flat, single-purpose modules (see table below)
│   ├── accounts/                # email + pass/ripasso
│   ├── agenix/                  # secrets management + encrypted secrets
│   ├── browsers/                # Firefox, userChrome/userContent, w3m
│   ├── desktop/                 # common desktop bits + GNOME
│   ├── discord/                 # Vesktop + Vencord
│   ├── emacs/                   # org-tangled Emacs config
│   ├── hosts/nixpavilion/       # host-specific config, disko layout, hardware scan
│   ├── neovim/                  # Fennel-based Neovim config (compiles to Lua via nfnl)
│   ├── shell/                   # zsh + starship
│   └── users/                   # per-user home-manager entrypoints
└── TODO.md
#+end_example

Every module follows the same shape: a top-level
=flake.nixosModules.<name>=\\
and/or =flake.homeModules.<name>= attribute, picked up automatically
and\\
wired into the =nixpavilion= host in
[[./modules/nixos.nix][=modules/nixos.nix=]].

** Installation

:CUSTOM_ID: installation
:END:

#+begin_note
Assumes an installer ISO is already booted. See the\\

general\\

#+end_note

*** 🧪 Enable experimental features
:PROPERTIES:
:CUSTOM_ID: test_tube-enable-experimental-features
:END:
Flakes and the =nix= command aren't on by default:

#+begin_src sh
sudo -i
export NIX_CONFIG="experimental-features = nix-command flakes"
#+end_src

*** ↙️ Clone this repo
:PROPERTIES:
:CUSTOM_ID: arrow_lower_left-clone-this-repo
:END:
#+begin_src sh
mkdir -p /tmp
cd /tmp
git clone --depth=1 https://github.com/rachitvrma/dotfiles.git
#+end_src

*** 💾 Partition with Disko
:PROPERTIES:
:CUSTOM_ID: floppy_disk-partition-with-disko
:END:
Run the latest
[[https://github.com/nix-community/disko][=nix-community/disko=]]\\
rather than the nixpkgs-pinned version. Confirm =disko-config.nix=
matches\\
the target host (defaults to\\
[[./modules/hosts/nixpavilion][=nixpavilion=]]):

#+begin_src sh
cd /tmp/dotfiles/modules/hosts/nixpavilion
nix run github:nix-community/disko/latest -- --mode destroy,format,mount ./disko-config.nix
#+end_src

*** 🐧 Install
:PROPERTIES:
:CUSTOM_ID: penguin-install
:END:
#+begin_src sh
mkdir -p /mnt/etc
cp -r /tmp/dotfiles /mnt/etc/nixos
nixos-install --no-root-passwd --root /mnt --cores 8 --max-jobs 1 --flake /mnt/etc/nixos#nixpavilion
umount -R /mnt
reboot
#+end_src

**** Edit config without =sudo=
:PROPERTIES:
:CUSTOM_ID: edit-config-without-sudo
:END:
Move =/etc/nixos= into your home directory so you can edit and rebuild\\
without root
([[https://wiki.nixos.org/wiki/NixOS_configuration_editors#Editing_as_normal_user][source]]):

#+begin_src sh
mkdir ~/etc
sudo mv /etc/nixos ~/etc/
sudo chown -R $(id -un):users ~/etc/nixos
sudo ln -s ~/etc/nixos /etc/
#+end_src

**** GPG / pass restoration
:PROPERTIES:
:CUSTOM_ID: gpg--pass-restoration
:END:

#+begin_important
Do this *before* the first =home-manager switch= / =nh os switch=
after\\
a reinstall --- Nix can't manage your GPG secret key material, and\\
=pass=/=pass-secret-service=/the email module's =passwordCommand= will
all\\
fail (blocking the rebuild) until it's restored.
#+end_important

Before wiping the old system:

#+begin_src sh
gpg --homedir ~/.local/share/gnupg --export-secret-keys --armor > gpg-backup.asc
#+end_src

Also make sure =~/.password-store= is backed up or pushed to a remote
--- the\\
key alone decrypts nothing without the encrypted store itself.

After reinstall, before rebuilding:

#+begin_src sh
mkdir -p ~/.local/share/gnupg
gpg --homedir ~/.local/share/gnupg --import gpg-backup.asc
gpg --homedir ~/.local/share/gnupg --edit-key <keyid> trust   # choose 5 (ultimate)
git clone <your-pass-store-remote> ~/.password-store
#+end_src

#+begin_note
=programs.gpg.homedir= is =~/.local/share/gnupg=, *not* =~/.gnupg=.
#+end_note

**** Miniflux credentials
:PROPERTIES:
:CUSTOM_ID: miniflux-credentials
:END:

#+begin_important
If Miniflux can't find these credentials, the rebuild fails because
its\\
systemd unit fails.
#+end_important

#+begin_src sh
sudo mkdir -p /etc/secrets/miniflux-admin-credentials
sudo chmod 600 /etc/secrets/miniflux-admin-credentials
#+end_src

#+begin_src txt
ADMIN_USERNAME=<username>
ADMIN_PASSWORD=something6charactersLong
#+end_src

**** Fastfetch images
:PROPERTIES:
:CUSTOM_ID: fastfetch-images
:END:
The fastfetch config pulls logos from\\
[[https://github.com/Maheswara660/fastfetch/][Maheswara660's fastfetch
repo]]:

#+begin_src sh
git clone --depth=1 https://github.com/Maheswara660/fastfetch/
cd fastfetch/images && git lfs pull
#+end_src

Then move the =images= directory into =~/.config/fastfetch/images=.
