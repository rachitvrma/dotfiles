#+TITLE: Architecture

* Layout

#+begin_example
flake.nix                  tack inputs + flake-parts mkFlake; auto-imports modules/
.tack/                     input pins (pins.toml -> pins.lock.json)
modules/*.nix              shared flake-parts modules, one concern per file
modules/<topic>/           a module that needs extra files (emacs/, agenix/)
modules/hosts/<name>/      default.nix assembles the host, _*.nix are host-only
modules/users/             user accounts and home modules
stow/<package>/            dotfiles for GNU Stow (see .stowrc, justfile)
scripts/{arch,nixos}/      distro specific helpers
#+end_example

* How the auto-import works

=importTree ./modules= returns every =.nix= file below =modules/= except
=flake.nix=, =secrets.nix= and anything whose name starts with =_=. Each file is
a *flake-parts module*, so it declares outputs:

#+begin_src nix
{ me, ... }:                     # flake-parts args: inputs, self, me, lib, ...
{
  flake.nixosModules.foo = { pkgs, ... }: {   # a NixOS module
    environment.systemPackages = [ pkgs.hello ];
  };
}
#+end_src

Files starting with =_= are *not* flake-parts modules. They are plain NixOS
modules (or data) that a flake-parts file imports explicitly, e.g. the
=_configuration.nix=, =_disko-config.nix= and =_hardware-configuration.nix=
next to a host's =default.nix=.

* Hosts

A host is =flake.nixosConfigurations.<name>= in =modules/hosts/<name>/default.nix=.
It gets *all* of =self.nixosModules= plus its own =_= files. That is fine for
one machine. With a second host, stop using =attrValues self.nixosModules= and
list the modules each host wants (or group them into =base=, =desktop=, ...
profiles).

* Shared values

=modules/meta.nix= defines the =me= argument (username, full name) so the
account name is written once.
